# Traffic Pi 使用说明

车辆行驶展示：参考 [最小演示 MCP 配置](../mcp/README.md)。打开工作台即进入重庆渝中半岛工作日场景；`start_rush_hour_demo` 会重新加载固定种子 42 生成的合成交通，并从 08:00 播放。

选择交通项目目录后，新建任务。首页四个任务入口会将提示填入输入框，确认后发送。

侧边栏 **MCP 工具** 保存当前项目的 `.pi/mcp.json`。支持本地命令及 JSON 参数数组（stdio）和服务器地址（流式 HTTP）。同名保存更新原配置。保存后刷新页面，按现有项目提示信任目录，再测试连接。测试会返回真实工具列表并关闭临时连接；不代表后台一直在线。

启用的服务器在新建或通过 `/reload` 重新加载会话时连接，单独刷新网页不会重连已有会话。工具以 `mcp_服务器名_工具名_摘要` 注册，名称截短并附摘要以适配模型名称限制。已有会话停用服务器后也会拒绝继续调用。HTTP 认证暂未提供表单，第一版用于本地或无需认证的服务。stdio 命令在所选项目目录执行。纯聊天（Chat only）模式不加载 MCP 或技能。

**专属技能** 复用 Pi 的技能管理，可添加自己的技能包。本仓库 `.pi/skills/` 预置三份交通技能，在选择并信任本仓库后加载；受限模式不会加载项目技能。其他项目可把这些技能目录复制到自己的 `.pi/skills/`。技能不会自行提供仿真能力，需要连接相应 MCP 工具。

文件浏览器、终端和 Git/worktree 随 **开发工具** 展开，默认折叠。模型配置在侧边栏；实际对话需配置有效供应商。开发启动为 `npm run dev`，访问 http://127.0.0.1:30141。
