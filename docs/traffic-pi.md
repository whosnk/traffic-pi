# Traffic Pi 使用说明

车辆行驶展示：参考 [最小演示 MCP 配置](../mcp/README.md)。首次进入 A/B Street 仿真模式时加载重庆渝中半岛工作日场景；`start_rush_hour_demo` 经同一切换保护与用户确认重新加载城市初始状态。顶部“城市交通 / 高速公路”共用一个画布；高速为双向三车道和出入口匝道，加载确认后从 08:00 以 1× 自动运行。

选择交通项目目录后，新建任务。首页四个任务入口会将提示填入输入框，确认后发送。

设置中的 **MCP 连接管理** 保存当前项目的 `.pi/mcp.json`。支持本地命令及 JSON 参数数组（stdio）和服务器地址（流式 HTTP）。同名保存更新原配置。保存后刷新页面，按现有项目提示信任目录，再测试连接。测试会返回真实工具列表并关闭临时连接；不代表后台一直在线。

启用的服务器在新建或通过 `/reload` 重新加载会话时连接，单独刷新网页不会重连已有会话。工具以 `mcp_服务器名_工具名_摘要` 注册，名称截短并附摘要以适配模型名称限制。已有会话停用服务器后也会拒绝继续调用。HTTP 认证暂未提供表单，第一版用于本地或无需认证的服务。stdio 命令在所选项目目录执行。纯聊天（Chat only）模式不加载 MCP 或技能。

**交通技能** 在侧边展示仿真控制、信号配时分析、方案对比评估、拥堵检测、拥堵缓解五项能力。悬停、键盘聚焦或点击可以查看处理步骤、关联工具和预期产出；开始分析会提交相应任务，Escape 可关闭面板。实际技能管理在设置中。本仓库 `.pi/skills/` 预置五份交通技能，在选择并信任本仓库后加载；受限模式不会加载项目技能。其他项目可把这些技能目录复制到自己的 `.pi/skills/`。技能需要连接相应 MCP 工具。

**任务导航** 包含仿真工作台、仿真实验、分析与报告、设置。默认打开重庆渝中半岛 A/B Street 主地图，Agent 对话在左，分析结果在右按需展开；窄屏通过侧栏的对话面板、结果面板切换。GIS 是分析与图层能力，SimTrend 是 SUMO 实验工具链，二者尚未与 A/B Street 实时同步。切换页面、收起工作区或打开文件仅改变显示，保留当前会话、草稿、共享仿真实例与命令接收，不自动暂停仿真时间。活动交通任务阻止会话与项目切换，需先完成决策或主动取消并确认恢复。顶部场景切换、任务保护和草稿保留规则见 [场景说明](scenarios.md)。

**分析结果** 只收录本次页面打开期间收到的成功 GIS 场景、道路／路口指标、指标采集和方案对比，按会话隔离，刷新后清空。点击历史 GIS 结果在地图回看，点击“返回最新结果”恢复最新场景；新结果不会打断历史回看。指标详情保留工具返回的字段、单位和时间，查看历史指标不会改变正在运行的仿真。普通回答及文字建议继续在聊天中查看。

文件浏览器、终端和 Git/worktree 随 **开发工具** 展开，默认折叠。模型配置在侧边栏；实际对话需配置有效供应商。开发启动为 `npm run dev`，访问 http://127.0.0.1:30141。


## 重庆城市拥堵与治理工作流

在主地图点击“检测当前拥堵点”，或调用 `detect_congestion`，会采集状态与道路指标、清理旧高亮、筛选疑似拥堵、标注并定位道路。检测期间可取消；切换分析页或收起工作区不会停止任务。道路卡及分析结果保留道路 ID、名称、排队、速度、采集时间与接口样本口径。点击结果中的定位可返回主地图。

当前筛选为排队 ≥5 辆且历史行程平均速度 ≤10 km/h 的未标定启发式规则。接口只覆盖有限道路，最多展示五处，不代表全路网；历史行程平均速度不是瞬时测速，状态与指标也不保证同时采集。数据缺失或调用失败时展示错误，不把缺失值当作改善。

道路、技能卡、结果栏和对话默认使用真实溯源；道路详情的“其他方式”保留明确的预设模型入口：

- **分析缓解方案**：承接检测快照，使用本地 A/B Street 控制桥；不支持时展示证据，不自动降级为预设。这里“真实”指本地合成交通仿真。
- **其他方式 → 预设模型推演**：只有主动选择时传递 `presetScenario:true`，不修改 A/B Street 配时；结果注明模型来源。

治理依次经过目标确认、原因证据、候选方案、用户选择授权、基准/候选验证、用户保留/恢复。真实验证从同一检查点出发，各推进 300 仿真秒，每 5 秒采样；表格并排展示目标及其他进口方向，提示其他方向等待增加。等待车辆秒由采样梯形积分估计，只说明本路口本轮观察。

普通状态/指标查询不授权配时写入。真实溯源会暂停并观察本地仿真、建立检查点；选定候选后才签发一次性 `taskId/approvalToken/version`，验证写入本地配时。比较结束还需用户决定保留或恢复。取消或执行失败尝试恢复任务起点；恢复失败明确提示并阻止场景、会话和项目切换，需人工核查，不能把错误提示解释成恢复成功。

GIS 历史图层、SUMO 历史任务与 A/B Street 结果各自保留来源；尚无统一道路 ID、轨迹同步或实时引擎桥。结构与未来接口约束见 [架构说明](traffic-pi-architecture.md)，本次验证见 [阶段1–3交付记录](traffic-pi-stages-1-3-validation.md)。
