# 场景与切换行为

场景类别是城市道路或高速公路；引擎与可视化是独立字段。GIS 属于分析与图层能力，不是交通场景。

- 重庆渝中半岛：A/B Street 主地图，工作日 08:00，合成需求种子 42。
- SUMO 场景：卡片从现有 Python 场景列表实时投影，当前已有四交叉口路网、南京南站网约车停车管理。名称、说明、能力以后端 scenario.json 为准。读到场景不等于 SUMO 可执行文件已就绪。
- 高速公路：规划占位，入口禁用；未建模、不可运行。

打开场景只进入界面，不运行实验。未信任项目、Python 不可用或场景读取失败时显示真实错误；不伪造可运行实验卡片。

## 可审计的切换规则

| 状态 | 行为 |
| --- | --- |
| A/B Street 检测或缓解任务活动中，包括等待选择、等待决策、恢复中 | 阻止场景、会话及项目切换；先完成保留／恢复，或主动取消并确认恢复成功 |
| Agent 执行中 | 阻止场景切换；等待结束或主动停止 |
| 打开分析、场景管理、文件，或收起工作区 | 只改变显示；共享 A/B Street 实例与命令接收继续，不隐式暂停或取消 |
| 已提交 SUMO jobs | 不取消；按会话及 scenario_id 保持归属，后台继续运行，返回可查 |
| SUMO 事故草稿与其他表单 | 在当前页面内按场景保留；切换清空空间选择并递增 revision，拒绝迟到草稿；不借用其他场景道路 ID |
| 历史结果 | 保持会话及原场景归属；切换不清空；A/B Street/GIS 临时结果与表单刷新后丢失，SUMO jobs 持久化 |

A/B Street 是页面中的共享实例，不是每会话独立仿真。刷新、关闭页面仍会触发生命周期清理；不要以刷新代替治理任务的保留／恢复操作。恢复失败必须核查，不能假定原配时已恢复。

## 扩展入口

在 lib/traffic-scenarios.ts 中定义场景展示元数据；SUMO 场景继续使用后端 scenario.json，不重复建立名称或能力表。新引擎应新增适配入口并明确 availability、capabilities、道路 ID 命名空间与结果来源。当前未实现道路 ID 转换、轨迹同步、MapLibre 覆盖 WASM 画布或引擎实时桥接。
