# 场景与切换行为

城市交通和高速公路共用同一个 A/B Street 工作台。GIS 为辅助空间分析，SimTrend/SUMO 保留独立实验入口，当前没有跨引擎同步。

| 顶部按钮 | 资源与初始状态 | 能力 |
| --- | --- | --- |
| 城市交通 | 重庆渝中半岛 yuzhong_core/weekday，08:00 暂停，种子 42 | 拥堵检测、真实溯源和用户授权后的配时验证 |
| 高速公路 | 自建 highway-demo/motorway，双向三车道及出入口／立交匝道，08:00 以 1× 自动运行，种子 42 | 播放、暂停、速度与地图交互；不提供城市信号治理 |

高速需求从 07:58 至 08:32 持续供给，08:00 已有车辆；08:35 本轮演示暂停，可点击“重新播放当前场景”。路网与需求均为合成数据，源文件、导入脚本和重建说明在 [highway](../third-party/abstreet/highway/README.md)。

切换前确认“当前场景进度将重置”。确认后注销旧接收实例，中止残留请求，销毁旧 iframe，清理道路气泡、高亮和相机状态，再加载目标初始状态。始终只有一个活动 iframe，不保存离开时车辆进度。对话、草稿与历史结果保留。

统一配置在 lib/traffic-scenarios.ts；地图、需求读取成功且控制桥的 map/scene/randomSeed 与配置一致才算就绪，iframe onLoad 不算加载成功。资源缺失、身份不匹配和 180 秒超时显示具体错误及重试／返回城市入口，不显示旧地图冒充新场景。

## 切换保护

| 状态 | 行为 |
| --- | --- |
| 检测、溯源、验证、等待选择／决策、恢复中 | 阻止场景切换；先完成或取消任务并确认恢复 |
| 恢复失败 | 独立记录“恢复未确认”，阻止新任务和切换；可重试恢复，或明确确认丢弃状态并重新初始化，后者不表述为恢复 |
| Agent 正忙、场景加载或控制操作尚未完成 | 阻止重复切换，说明原因 |
| GIS、SUMO、纯对话、文件预览与收起工作区 | 只改变显示，保留 A/B Street 实例，不隐式暂停；原命令接收继续 |
| 历史结果 | 按会话保留，注明场景及 runId 批次；其他场景／旧批次不允许定位、高亮或启动配时操作 |

浏览器命令由接收窗口注册时附带 scenarioId/runId，模型不填写。响应必须与当前运行批次匹配；旧实例回复会被拒绝。旧 start_rush_hour_demo 保持城市语义，经同一保护及确认流程加载，并在桥确认后返回成功。

A/B Street 是页面共享实例，切换会话不会重建；结果及治理任务按会话隔离。刷新后临时结果清空，不恢复执行任务。刷新或关闭页面不能代替保留／恢复。

SUMO 场景仍从 Python 元数据读取，已提交 jobs 和表单沿用原归属。没有接入 SUMO 与 A/B Street 的道路 ID 转换、轨迹同步或实时联动。
