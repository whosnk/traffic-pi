# 拥堵分析

调用已连接的 `detect_congestion` 工具（名称可能带 MCP 前后缀），由它统一准备场景、读取路况、识别拥堵、地图标注并返回结果。此工具无需模型填写参数或会话标识。

保留当前仿真运行、暂停及速度，不重置、快进或修改信号方案。每次请求只检测一次；再次检测必须创建新调用。

按结果顺序说明道路名称或内部 ID、排队车辆数、平均车速 km/h、累计延误秒及采集时间。说明速度是接口提供的行程累计平均值，筛选为瞬时快照规则，尚非经标定的评价标准，查询范围不代表全部路网。缺失数据不等于没有拥堵。

查看第二个拥堵点等请求复用最近一次结果的 roadId，调用 `focus_on_road`，不重新检测。失败时说明工具实际错误；工具未连接或项目不受信任时说明如何检查，不声称已经执行。
