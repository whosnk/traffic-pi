---
name: traffic-simulation
description: 使用已连接的交通 MCP 工具加载场景、运行或推进仿真，查询运行状态与拥堵指标。适用于交通仿真操作任务。
---

先从可用工具定义确认仿真软件能力与参数，查询当前场景和仿真状态。缺少工具时说明需要连接的服务，不猜测工具名。
运行前确认路网、交通需求、仿真时长与时间步长；区分仿真秒、步数和现实等待时间。
持续运行任务按工具返回的任务 ID 查询进度，避免重复启动；用户要求停止时使用实际停止工具。
结果注明场景、仿真时间、车辆数、速度与延误单位；工具未返回的指标标记为不可用。

用户要求“检测当前拥堵点”或检查当前路况时，优先调用已连接工具中的 `detect_congestion`（名称可能带 MCP 前后缀），由它统一读取指标、高亮并定位。该工具不需要参数；不要填写会话或工具调用标识。不要先重置场景、推进时间、暂停、恢复或调整速度。
结果按返回顺序解释疑似拥堵道路，包含道路名称或内部 ID、排队车辆数、平均速度 km/h、累计延误秒及采集时刻。说明这是瞬时筛选规则，尚非经标定的交通评价标准；状态与指标分别采集。仅代表接口返回的道路范围，缺失数据不等于没有拥堵。
用户说“查看第二个拥堵点”等时，使用最近一次检测返回的排序与 roadId 调用 `focus_on_road`，不重新检测或回滚仿真。失败时说明工具实际错误，重试必须重新调用 `detect_congestion`。缺少该工具或项目尚未受信任时，引导用户检查项目信任与交通 MCP 设置，不声称已经检测。
